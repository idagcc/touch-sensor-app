Touch Player 1.3.0 adds a standalone Windows app alongside the native macOS app.

- `0` switches from holding to playback, pauses, then resumes.
- `1` stops and rewinds playback and returns to holding.
- Folder-based videos, JSON command mappings, serial/COM-port selection, custom canvas dimensions and display selection.
- Serial startup filtering, automatic recovery, USB identity matching, increasing retry delays, and optional heartbeat monitoring.
- Keyboard testing with `0` and `1`; no Arduino required for the demo videos.

Downloads contain original demo clips. Replace one file in each media folder with your own videos and reload.

Mac: extract `TouchPlayer-macOS.zip` and open Touch Player.app. Windows: use the Setup executable or extract the portable ZIP and keep its contents together. Windows installers are unsigned; Mac builds are ad-hoc signed and not Developer ID notarized. Physical Arduino, driver, display and audio checks remain necessary for the installation.
